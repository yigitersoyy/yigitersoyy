## 🚀 Featured Work

### 🔬 Latent CSI-BiLSTM — *IEEE SIU 2026*
`PyTorch` `Latent Diffusion` `BiLSTM` `Transfer Learning`

Extended the LatentCSI framework with a temporal BiLSTM encoder, a multi-task activity classifier and transfer learning to synthesize human-activity imagery from raw Wi-Fi CSI signals.
**Result:** 50.1% FID improvement over the baseline at ~330 FPS.

### 🔒 Canias ERP Reporting Assistant
`Ollama` `Local LLMs` `Web App`

Privacy-preserving web app that connects live ERP data to on-premise LLMs so management can generate structured analytical reports on demand. Cut manual reporting cycles by **75%** with no external data exposure.

### 📑 Contract & BOQ Planning Agent
`Copilot Studio` `Document Intelligence`

Autonomous agent that parses, extracts and benchmarks risk clauses across 100+ page contracts (PDF/DOCX/XLSX) with source-referenced citations. Accelerated legal and commercial review by **60%**.

### 🧑‍💼 HR Matchmaker Agent
`Copilot Studio` `Power Automate`

End-to-end CV evaluation pipeline that semantically matches applicants to open requisitions, reducing initial screening time by **65%**.

### 🧠 Local LLM Experimentation & Offline RAG Stack
`Ollama` `LM Studio` `LangChain` `FAISS` `Chroma`

Benchmarked quantized open-weight models (Llama 3, Mistral 7B, 4-bit/8-bit GGUF) on consumer GPUs, and built local vector-search pipelines to evaluate air-gapped RAG feasibility.

### 🌱 Smart Greenhouse Controller — *MUISC 2026*
`Arduino` `IoT` `C/C++`

Embedded system using multi-sensor telemetry (soil moisture, light, tank level) to autonomously control irrigation and send threshold alerts.
